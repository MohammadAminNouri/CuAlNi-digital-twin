# Examples

`run_primary_alloy.py` runs the default Cu-14.3Al-4.3Ni wt% composition through the orchestration layer without assuming a TDB, CIF, ML dataset, experimental file, or LPBF calibration. It writes an audit JSON in which only deterministic composition/descriptors are available.

```bash
python examples/run_primary_alloy.py
```

The committed `primary_alloy_composition_only.json` is generated by that script. Its unavailable sections are part of the example: they demonstrate that the platform never fabricates phase fractions, transformation temperatures, properties, XRD peaks, or an AM score.

`build_example_reports.py` converts that same JSON into committed HTML and PDF audit reports:

```bash
python examples/build_example_reports.py
```

To exercise a scientific calculation, supply your own licensed/cited input through the Streamlit interface. Empty CSVs in `data/templates/` document accepted column names and are not datasets.
